# 🚀 Products & Projects

## 🔐 OGI Control
### Server Management & Security Platform
**Private / In Development**

OGI Control is a security-focused server management platform designed around a **desktop control plane and autonomous server agents**.

```text
Windows Desktop Control Plane
            │
            │ mTLS / gRPC
            ▼
        Secure Gateway
            │
            ▼
        Go Server Agent
            │
    ┌───────┼────────┐
    ▼       ▼        ▼
 Firewall  Logs   Security Events
```

### Core Architecture

- Go modular control plane
- Independent Go server agent
- Outbound-only mTLS gRPC communication
- Secure server enrollment
- Agent identity and certificate lifecycle
- PostgreSQL persistence
- Role-based access control
- TOTP MFA
- Step-up authentication for critical actions
- Security event collection
- Firewall management
- Local audit trail
- Desktop application built around Tauri

### Security Design

OGI Control is being designed around:

- least privilege
- fail-closed behavior
- strong identity boundaries
- auditable administrative operations
- secure enrollment
- local resilience when the control plane is offline
- zero unnecessary inbound agent ports

> Source code is currently private while the product architecture and security model are under active development.
